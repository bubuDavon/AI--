# 智多星网站源代码（可编辑版）

## 打开网站

双击 `index.html` 可查看首页。为了确保搜索、下载和浏览器存储功能都正常，建议用本地网页服务预览，而不是直接以文件方式打开。

## 常用文件

- `index.html`：学习工作台入口和整体页面框架。
- `app.css`：页面颜色、尺寸、排版与响应式样式。
- `app.js`：学习流程、评分、报告、保存和交互逻辑。
- `flow-data.js`：摸底题、课程检查点、结课题和示例数据。
- `app-data.js`：知识卡数据。
- `knowledge.html`：知识库首页。
- `read/`：课程、案例、边界和资料说明页面。
- `zhiduoxing-icon.png`：左上角智多星助教图标。
- `favicon.png`：浏览器页签图标。

## 修改后发布

1. 修改文件后，先打开 `index.html` 检查首页、知识库和“看看完整示例”。
2. 将整个文件夹压缩成 ZIP，确保 `index.html` 位于压缩包内的项目根目录。
3. 登录 Netlify，打开项目 `peppy-pasca-0ac51c`。
4. 在 Production deploys 区域上传新的 ZIP。
5. 发布后打开 `https://peppy-pasca-0ac51c.netlify.app/` 检查更新。

## 数据与功能边界

学习记录保存在访问者自己的浏览器中，没有云端数据库和账号系统。开放作品反馈使用页面内规则检查，没有接入外部大模型接口。源码包不包含密码、账号凭据或 Netlify 认领令牌。

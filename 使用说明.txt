智多星官网 + 学习系统整合版
需要 Node.js 20+。复制 .env.example 为 .env，分别填写官网 Agent 和学习 Agent 配置，然后运行 npm install、npm start，访问 http://localhost:8787。
官网位于 /，学习系统位于 /learning/，官网首页、个人中心和两个分版页面都可进入学习系统。
从入学准备开始。可通过“看看完整示例”快速体验，示例不会覆盖个人记录。
流程：设定目标→课前摸底→三个学习检查点→综合实操与评分。
学习助教通过服务端接入独立的 OpenHex Agent，支持流式输出与多轮对话；未配置或连接失败时可查本地知识卡。官网在线咨询使用另一套独立 Agent。开放作品仍按规则检查，尚未使用大模型语义批改。
Netlify 部署运行 npm run build，发布 dist 目录，只需配置两套 OpenHex 的 API Key 和 Agent ID。官网留资、账户、登录态和多轮 conversationId 全部使用浏览器本地存储。
